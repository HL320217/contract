# 项目结构说明

## 目录结构（当前）

```
contract/
├── app/
│   ├── main.py                 # GUI入口
│   ├── contract_generator.py   # 生成器核心逻辑
│   ├── template_processor.py   # 模板处理（仅支持 .docx）
│   ├── data_processor.py       # 数据处理（.xlsx/.csv/.json）
│   ├── config.py               # 配置与常量
│   ├── build.py                # 打包脚本
│   └── img/                    # 图标与图片资源
├── docx/                       # 文档说明
│   ├── 项目结构说明.md
│   ├── 打包说明.md
│   └── 软件使用说明书.md
├── dist/                       # 本地打包产物，不纳入 Git
│   └── 合同批量生成器.exe      # 打包生成的可执行文件
├── test_templates/             # 本地合同模板，不纳入 Git
│   ├── employment_contract.docx
│   ├── service_contract.docx
│   └── rental_contract.docx
├── test_data/                  # 本地测试数据，不纳入 Git
│   ├── employee_data.csv
│   ├── service_data.csv
│   └── rental_data.json
├── generated_contracts/        # 运行时自动创建
├── temp/                       # 运行时自动创建
└── README.md
```

## 核心模块

- `app/main.py`：应用入口，tkinter 图形界面
- `app/contract_generator.py`：生成器协调模板与数据，输出合同
- `app/template_processor.py`：模板加载与变量提取（`.docx`）
- `app/data_processor.py`：数据加载与列建议（`.xlsx/.csv/.json`）
- `app/config.py`：应用配置（窗口、格式、路径等）
- `app/build.py`：PyInstaller 打包脚本（入口为 `app/main.py`）
- `app/img/`：应用图标与图片资源

## 运行与打包

- 运行：`python app/main.py`
- 打包：`python app/build.py`
- 依赖安装（源码运行）：`pip install -r app/requirements.txt`

## 模板与数据格式

- 模板变量语法：`{{变量名}}`
- 模板类型：仅支持 `DOCX`（Word）
- 数据源类型：`Excel(.xlsx)`、`CSV(.csv)`、`JSON(.json)`

## 工作流程

1. 启动程序（`app/main.py`）
2. 选择模板（`app/template_processor.py`）
3. 选择数据（`app/data_processor.py`）
4. 映射变量并生成（`app/contract_generator.py`）
5. 输出文件写入 `generated_contracts/`

## 维护与扩展

- 修改配置：`app/config.py`
- 扩展数据格式：在 `app/data_processor.py` 添加读取实现
- 优化性能：在生成与数据处理逻辑中分块、缓存等
