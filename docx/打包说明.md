# 合同批量生成器打包说明

## 快速打包步骤

1. 安装依赖（项目根目录）：
   ```bash
   pip install -r app/requirements.txt
   ```

2. 运行打包脚本（项目根目录）：
   ```bash
   python app/build.py
   ```

3. 获取可执行文件：
   - 生成于 `dist/合同批量生成器.exe`

## 打包内容

- 入口脚本：`app/main.py`
- 收集资源：`generated_contracts/`、`temp/`、`img/`
- 隐式依赖：`pandas`、`openpyxl`、`docx`、`jinja2`
- 组件收集：`--collect-all=docx`（确保 `python-docx` 资源完整）

不包含：`test_templates/`、`test_data/`（示例文件用于开发与测试，非运行依赖）

## 分发建议

- 直接分发 `dist/合同批量生成器.exe` 即可（用户无需安装 Python）
- 若以源码分发：提供 `app/` 与 `app/requirements.txt`，用户运行 `python app/main.py`

## 常见问题

- 打包失败：确认依赖安装完整，并在干净环境重新打包
- 运行后资源缺失：检查 `--add-data` 参数是否覆盖 `generated_contracts`、`temp`、`img`
- 图标未显示：确认 `img/favicon.ico` 或 `img/logo.png` 是否存在

## 测试清单

- 能选择 `.docx` 模板
- 能选择 `.xlsx/.csv/.json` 数据
- 能生成 `.docx` 合同并写入 `generated_contracts/`
- 关于与反馈对话框显示正常
- 应用图标显示正常
